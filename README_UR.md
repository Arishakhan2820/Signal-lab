# تعلیمی ایم ایل پراجیکٹ (اردو گائیڈ)

> **صرف تعلیمی مقصد کے لیے۔** یہ پراجیکٹ سیکھنے کے لیے بنایا گیا ہے (محفوظ بیک اینڈ اور مشین لرننگ)۔ یہ **طبی آلہ نہیں** ہے، **تشخیص یا اسکریننگ کا ٹول نہیں** ہے، اور پیشہ ور مدد کا متبادل نہیں ہے۔
> اس میں صرف **فرضی (synthetic) ڈیٹا** استعمال ہوتا ہے۔ براہِ کرم اپنی اصل ذاتی یا صحت کی معلومات درج نہ کریں۔
> اگر آپ مشکل میں ہیں یا خطرے میں ہیں تو مقامی ایمرجنسی سروسز یا کسی قابلِ اعتماد شخص سے رابطہ کریں۔

## اس میں کیا کیا ہے
1. **بیک اینڈ (FastAPI + PostgreSQL):** لاگ اِن، کوکی سیشن، CSRF سے بچاؤ، رضامندی (consent) دینا اور واپس لینا، ڈیٹا مٹانے کا ٹریک ہونے والا عمل، اور حفاظتی گیٹس۔ اس میں ابھی کوئی اصل سوالنامہ یا ماڈل نہیں ہے، اس لیے اسسمنٹ اور انفرنس "دستیاب نہیں" جواب دیتے ہیں۔
2. **ایم ایل مشق (`ml/`):** ایک سروے ڈیٹا ٹیبل پر آف لائن تجربہ۔ نتیجہ: ماڈل اندازے سے بس تھوڑا بہتر ہے (ROC-AUC تقریباً 0.55)۔
3. **ڈیمو صفحہ (`web-demo/index.html`):** "Signal Lab"، جہاں آپ فرضی ویلیوز بدل کر دیکھتے ہیں کہ ماڈل کا اسکور کیسے بدلتا ہے۔

## ڈیمو صفحہ کیسے کام کرتا ہے
1. **سیکھنا (پہلے سے ہو چکا):** لاجسٹک ریگریشن ماڈل نے 1429 قطاروں سے 20 کالمز میں سے ہر ایک کے لیے ایک "وزن" سیکھا۔ یہ وزن `ml/demo_model.json` میں محفوظ ہیں۔
2. **آپ کی ویلیوز:** صفحہ ہر ویلیو کو ڈیٹا کی اوسط سے ملاتا ہے، اس کے وزن سے ضرب دیتا ہے، اور سب کو جمع کرتا ہے۔
3. **اسکور:** جمع کو 0 اور 1 کے درمیان کے عدد میں بدلا جاتا ہے (sigmoid)۔ نیلی پٹیاں اسکور کو اوپر دھکیلتی ہیں اور سرمئی نیچے۔
4. سارا حساب آپ کے براؤزر میں ہوتا ہے۔ کوئی سرور نہیں، اور کچھ بھی کہیں نہیں بھیجا جاتا۔

## "Reality check" کا مطلب
کسی ماڈل پر بھروسا کرنے سے پہلے اسے ایسی قطاروں پر آزمایا جاتا ہے جو اس نے کبھی نہیں دیکھیں۔
- **ROC-AUC:** 0.50 کا مطلب سکہ اچھالنا، 1.00 کا مطلب بالکل درست۔ ہمارا ماڈل تقریباً 0.55 ہے۔
- **PR-AUC:** اندازہ لگانے والے ماڈل کا نتیجہ تقریباً 0.167 ہوتا ہے، ہمارا 0.19 ہے۔

مطلب: یہ ماڈل اندازے سے بس ذرا بہتر ہے، اس لیے اس کے اسکور کا **کسی بھی شخص کے بارے میں کوئی مطلب نہیں**۔ وجوہات: ڈیٹا میں علامات یا سوالنامے کے جوابات نہیں (صرف عمر، آمدنی، اثاثے وغیرہ)، لیبل `depressed` کا مطلب دستاویز میں درج نہیں، اور ڈیٹا کا ماخذ اور لائسنس ابھی تصدیق شدہ نہیں۔

## کیسے چلائیں
```bash
pip install -e ".[dev,ml]"
python -m pytest -q          # ٹیسٹ (مقامی PostgreSQL چاہیے)
python ml/audit_and_train.py # آف لائن مشق (ml/data/b_depressed.csv درکار، گِٹ میں شامل نہیں)
```
ڈیمو صفحہ دیکھنے کے لیے `web-demo/index.html` کو براؤزر میں کھول لیں۔
