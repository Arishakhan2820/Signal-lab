Show the math

Each push = weight × (your value − dataset average) ÷ spread. Add all pushes to the starting value, then squeeze with a sigmoid to get 0–1.

Under the hood

This demo sits on top of a security-first backend built as a portfolio project.

Secure sessions

HttpOnly cookies, CSRF tokens bound to the session, Origin checks, refresh single-flight, server-side revocation checks.

Row-level security

PostgreSQL RLS forced on every table. Tests prove one user cannot read another’s rows.

Consent and erasure

Withdrawing consent stops processing instantly and starts a tracked, retryable deletion workflow with backup-restore replay.

Safety gates

Assessments and inference stay disabled until review gates are approved. No fabricated scores or risk labels.

Honest ML

Grouped cross-validation, leakage check, model card from a real run, results reported even when weak.

Engineering hygiene

Typed config with production guards, redacted logs, OpenAPI contract test, CI with secret scanning, written threat model.

Stack: FastAPI · PostgreSQL + RLS · Supabase Auth · scikit-learn · vanilla JS. Not built yet: Google login, email, admin dashboard.
